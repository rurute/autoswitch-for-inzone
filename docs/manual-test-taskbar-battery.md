| 項目 | 値 |

| モニター | 1 枚（3440×1440、表示倍率 100%） |

## 分担

- **作者**: アプリの終了・配置・起動、Buds の出し入れ、テーマや表示倍率の変更、全画面、Explorer の再起動、表示の確認。
- **作業環境**: アプリのログ（`%LOCALAPPDATA%\AutoSwitchForInzone\logs\AutoSwitchForInzone.log`）の読み取り、画面写真の撮影、判定と記録。
